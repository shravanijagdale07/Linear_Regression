# 🎓 Student Performance Prediction

A Machine Learning project that predicts a student's Performance Index based on study habits and academic factors.

## 🚀 Live Demo

[Open Student Performance Prediction App](https://linearregression-ljh5cwkhdewtyzc5zkc2js.streamlit.app/)

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Linear Regression
- Git & GitHub

## 📌 Features

- Predicts student Performance Index
- Uses Linear Regression
- Takes student academic and lifestyle details as input
- Deployed using Streamlit Community Cloud

- app.py
- model.pkl
- Student_Performance.csv
